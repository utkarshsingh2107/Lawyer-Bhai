### IF THAT DOESN'T WORK:

1. **Open Command Prompt** (not PowerShell)
   - Press `Win + R`
   - Type `cmd`
   - Press Enter

2. **Navigate to your project:**
   ```
   cd D:\CODE
   ```

3. **Start the server:**
   ```
   npm run dev
   ```

4. **Open browser to:**
   ```
   http://localhost:3000/
   ```

## ⚠️ IF YOU SEE "npm is not recognized"

**This is normal!** Node.js was just installed.

**Solution:** Close your terminal and open a **NEW** one, then try again.

Windows needs a fresh terminal to recognize the newly installed Node.js.
